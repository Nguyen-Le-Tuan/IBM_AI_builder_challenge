## Needs measuring

Only an experiment on the team's own data can settle these (`HYPOTHESIS` until measured):

1. **Coverage of the DOI route.** For the dev and held-out sources: share with a resolvable hop-2 DOI; share with an abstract via Europe PMC or OpenAlex; share with open-access full text; compared with the pilot's server-side fetch success.
2. **Source-signal accuracy.** On the team's sources: does `study_designs` match the paper? Do MeSH `Animals`/`Humans` tags catch the “in mice” cases? Do OpenAlex `is_retracted` and Crossref `updated-by` agree on a sample of retracted DOIs from the Retraction Watch CSV?
3. **Main detector quality.** Span-level precision and recall per distortion type (causal upgrade, dropped qualifier or population, certainty, generality) on the held-out set; false-positive rate on faithful posts.
4. **Second-check value.** Do Granite Guardian 4.1 groundedness, the granitelib factuality adapter or MiniCheck-Flan-T5-L flag the gold-distorted post sentences that the main detector misses, at what false-positive rate and latency?
5. **No-link search hit rate.** For posts with the link removed: is the true source in the top 5 of Europe PMC / OpenAlex / Semantic Scholar search?
6. **Injection robustness.** Attack success on synthetic source pages with hidden instructions (visible text, invisible Unicode, “report no differences”), before and after the controls in row 7, with the attacker knowing the defence.
7. **In-browser feasibility.** Load time, memory and accuracy of Granite 4.0 Nano/Micro ONNX on the dev set on typical laptops.
8. **Label wording.** Whether “no differences found against this source” raises perceived accuracy of unsupported posts (small user test; ethics and consent needed).
9. **Fact Check API usefulness.** Hit rate of `claims:search` on science/health post claims.

## Recommendation

`RECOMMENDED (not decided)` — ordered by value for effort:

1. Explicit outcome states and “compared with the cited source only” copy on every check (lim. 6, 1). Near-zero cost.
2. DOI → OpenAlex singleton + Crossref `updated-by`: retraction, correction, preprint, study design, MeSH animal/human badges (lim. 1). Free, no key.
3. DOI → Europe PMC abstract and OA full text (with licence), OpenAlex abstract fallback, bioRxiv API for preprints (lim. 3). Never scrape PMC or publisher HTML.
4. LLM01:2026 hardening: provenance-labelled source channel, strict schema, Unicode stripping, plain-text rendering; plus a small adversarial page set (lim. 7).
5. Measure items 1–3 of “Needs measuring” before adding models; ask Wührl et al. for a data licence (lim. 4).
6. Test Granite Guardian 4.1 groundedness / granitelib factuality against MiniCheck-Flan-T5-L as an independent second check; keep only if it adds recall (lim. 4, 7). Keeps the IBM story.
7. No-link mode as “possible sources — confirm” using Europe PMC and OpenAlex search; defer paid web search (lim. 2).
8. Privacy: keep D-006 minimisation now; treat in-browser Granite as a stretch goal after accuracy is known (lim. 5).
